# Kunooze Library Reader v1.2.0

This is the public Android release of the **student reader** for Kunooze Library.

## Included in this release

The attached `kunooze-library-reader-v1.2.0.apk` is a signed production APK for Android. It provides an Arabic RTL student experience for browsing academic years and subjects, reading published text lessons, opening owner-approved Google Drive PDFs, and using the in-app student guide. No student account is required.

## Important installation note

If you installed an older v1.1 copy, uninstall it before installing v1.2.0 because this release uses a replacement signing certificate. Published academic content is not deleted by uninstalling the older local app.

This repository and release intentionally contain the **reader APK only**. The owner publisher app, source code, signing material, and Firebase configuration remain private.
