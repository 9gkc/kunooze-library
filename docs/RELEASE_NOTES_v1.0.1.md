# Kunooze Library Reader v1.0.1

This corrective release restores the university structure used by Kunooze Library. The Reader now presents the academic route as **Stage → First Semester or Second Semester → Subject → Numbered Lecture**. It does not introduce a separate course level or a reader guide page.

## Included corrections

| Area | Correction |
|---|---|
| Academic navigation | The four stages are the first entry point, and each stage leads only to its two semesters. |
| Terminology | Student-facing labels use **subject** and **lecture**, not an additional course category. |
| Lecture order | Publisher-assigned lecture numbers are mandatory for new content and take priority. Legacy records use a stable numeric-title and ID fallback. |
| Branding | The familiar Kunooze shield has been restored and refined for small Android surfaces. |
| APK compatibility | The production certificate remains unchanged. The package includes v1, v2, and v3 signature schemes in their applicable Android ranges. |

No Firestore collection, document identifier, application ID, or student content was migrated or removed for this release.
