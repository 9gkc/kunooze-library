# CyKun Reader v1.0.0 — production release

This production build keeps the public app identity at **v1.0.0** while delivering the final release polish for the student Reader.

## Included

- Unified **Updates** feed combining owner announcements and newly published learning notifications.
- Deterministic notification navigation to the related subject item, lecture, or resource where a valid target is available.
- Compatibility with legacy and modern published content records.
- Corrected shield launcher-icon scale and adaptive-icon safe area without redrawing the original artwork.
- Official release naming with all test-environment labels removed.
- Arabic RTL reading experience for stages, semesters, subjects, lectures, text lessons, and approved PDF resources.

## Distribution boundary

This repository distributes the signed Reader APK and student-facing documentation only. It does not include source code, Publisher workflows, Firebase configuration, credentials, signing material, or unpublished content.

## Integrity

Verify the downloaded APK against the SHA-256 value in [VERIFICATION.md](VERIFICATION.md) or [checksums.txt](../checksums.txt) before installation.
