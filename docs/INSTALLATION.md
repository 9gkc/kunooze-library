# Install CyKun Reader

CyKun Reader is distributed for Android through the [official Releases page](https://github.com/9gkc/cykun/releases) when a verified Reader build is listed.

## Install

1. Download the Reader APK from the official release page.
2. Open the downloaded file on your Android device.
3. If Android requests permission for the download source, review the prompt and allow installation only when the file came from the official CyKun release.
4. Open **CyKun** while connected to the internet, then select your academic stage and semester.

## Update safely

Install an update directly over an existing official CyKun installation whenever Android offers **Update**. This preserves the installed app's local preferences.

If Android does not offer an update, confirm that the installed app was downloaded from an official CyKun release before removing anything. A package signed by a different identity is a separate application and cannot replace the official installation.
