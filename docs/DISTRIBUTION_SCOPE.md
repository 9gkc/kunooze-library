# Public Distribution Scope

This public repository is the student-facing home of **CyKun Reader** for Android.

| Included | Not included |
|---|---|
| Official Reader release links | Management applications or workflows |
| Installation and verification guidance | Credentials, configuration records, or signing material |
| Public Reader showcase images | Implementation files or unpublished academic content |
| Official public community links | Internal operational documentation |

The [Releases page](https://github.com/9gkc/cykun/releases) is the authoritative source for Reader downloads when a verified build is available.
