# CyKun Public Distribution Scope

The public **CyKun** repository is the official download location for the student Reader. It is intentionally small, reviewable, and focused on safe distribution.

| Available publicly | Restricted to the private owner workspace |
|---|---|
| Signed CyKun Reader APK | Publisher application and publishing workflow |
| Release notes, checksum, and signature record | Source code and Firebase configuration |
| Authentic product screenshots | Signing keys and build secrets |
| English student documentation | Unpublished material and student information |
| Official community and developer links | Owner-only operational records |

Students should share the official release link without modifying the APK. The Reader does not require a student account and does not distribute the publisher application.

## Trust boundary

Only the links shown in this repository, its releases, and the Reader’s in-app Community tab are official project destinations:

| Official destination | Link |
|---|---|
| CyKun public releases | [github.com/9gkc/cykun/releases](https://github.com/9gkc/cykun/releases) |
| CyS4Ever community | [t.me/cys4ever](https://t.me/cys4ever) |
| Developer profile | [Ali Alkarar on LinkedIn](https://www.linkedin.com/in/9gkc/) |

CyKun never distributes credentials or asks students for passwords, one-time codes, or sensitive identity details through those links.
