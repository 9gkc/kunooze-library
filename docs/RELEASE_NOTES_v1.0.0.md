# CyKun Reader v1.0.0 — Public Community Release

This is the signed Android Reader release for the public **CyKun** launch. CyKun means **Cyber Kunooze / سايبر الكنوز**.

## Included

| Asset | Description |
|---|---|
| `cykun-reader-v1.0.0.apk` | Signed Android Reader APK for student use. |

## What is included

| Area | Outcome |
|---|---|
| Official community | A dedicated in-app Community tab links to the official [CyS4Ever Telegram channel](https://t.me/cys4ever). |
| Developer presence | The same Community tab links to [Ali Alkarar’s official LinkedIn profile](https://www.linkedin.com/in/9gkc/). |

| Learning formats | Published text lessons and owner-approved PDF links remain available without student sign-in. |
| Shield identity | The approved shield artwork remains unchanged. |

## Update behavior

The user-visible version is `1.0.0`; Android version code `10` is intentionally higher than prior official CyKun builds. The package remains `com.alkarara.kunooze.library_app`, and the established production signing certificate remains unchanged. Android can therefore update an official existing Reader installation directly.

For verification, compare the APK SHA-256 checksum:

```text
df24f9196e2b7c31f42b798ad44a8abf649ad3906a0b379035d600d29fcc0b87
```

This public release contains the Reader APK only. The publisher application, source code, signing keys, Firebase configuration, owner workflow, and unpublished material remain private.
