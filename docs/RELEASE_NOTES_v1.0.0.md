# Kunooze Library v1.0.0

This is the official public production release of the **Kunooze Library** Android reader for students.

## Included

| Asset | Description |
|---|---|
| `kunooze-library-reader-v1.0.0.apk` | Signed Android Reader APK for student use. |

## Highlights

The Reader provides Arabic right-to-left navigation through the academic path of stage, semester, subject, and learning material. It supports published text lessons, owner-approved PDF resources, search, and temporary owner-published announcements or timetable entries.

Students do not need an account. Download the APK from this release, follow the [installation guide](https://github.com/9gkc/kunooze-library/blob/main/docs/INSTALLATION.md), and compare its SHA-256 checksum if verification is required:

```text
25149dba1186c3d17dacd3961544eed47de15e07b6ba02447a83f51e8ac6fed6
```

This public release intentionally contains the Reader APK only. The publisher application, source code, signing keys, Firebase configuration, and owner workflow remain private.
