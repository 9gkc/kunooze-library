# CyKun Reader v1.0.0

## Public Student Release

This is the signed public Android Reader release for **CyKun**. It is the distribution baseline for students and is designed around a clear, university-aligned study route.

| Release item | Details |
|---|---|
| APK | `cykun-reader-v1.0.0.apk` |
| User-visible version | `1.0.0` |
| Android version code | `10` |
| Download | [Official release asset](https://github.com/9gkc/cykun/releases/download/v1.0.0/cykun-reader-v1.0.0.apk) |
| Verification | [Verification record](VERIFICATION.md) |

## Included experience

| Area | What students receive |
|---|---|
| Academic navigation | **Stage → First or Second Semester → Subject → Numbered Lecture**. |
| Learning formats | In-app text lessons and owner-approved PDF resources. |
| Order | Explicit publisher lecture numbers, with a stable fallback for older numbered titles. |
| Student access | No student sign-in or registration requirement. |
| Community | An in-app Community tab for the official CyS4Ever channel and developer profile. |
| Trust reminder | A clear notice that official community links do not ask for passwords or verification codes. |

## Update compatibility

The version name is intentionally `1.0.0` for the public baseline, while Android version code `10` preserves in-place update eligibility from earlier official production releases carrying the same package identity and signing certificate.
