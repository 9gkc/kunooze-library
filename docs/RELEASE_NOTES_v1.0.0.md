# Kunooze Library v1.0.0 — Redesign Build 7

This is the redesigned production build of the **Kunooze Library** Android Reader for students.

## Included

| Asset | Description |
|---|---|
| `kunooze-library-reader-v1.0.0.apk` | Signed Android Reader APK for student use. |

## What changed

The Reader was rebuilt around a clearer Arabic academic workspace. It introduces a new original library mark, a consistent dark visual system, higher-contrast Arabic typography, a focused Home dashboard, refined catalogue cards, and unified motion between academic screens.

The academic and content model remains unchanged: students still navigate from stage to semester, subject, and numbered lectures. They can continue reading text lessons, opening owner-approved PDFs, searching the published catalogue, following lecture continuity with previous/next controls, and viewing active announcements or timetable entries without creating an account.

## Update behavior

The package remains `com.alkarara.kunooze.library_app`, version `1.0.0`, with Android version code `7`. Devices already using the official production build with code `6` can update directly because the production signing identity is unchanged.

For verification, compare the APK SHA-256 checksum:

```text
f6bb3d24e7247f22672b462e8904fd2d55772e9c8c79852e480649afafeb1a12
```

This public release intentionally contains the Reader APK only. The publisher application, source code, signing keys, Firebase configuration, and owner workflow remain private.
