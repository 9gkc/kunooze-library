# Changelog

## v1.0.0 — Production Refresh (15 August 2026)

This signed Reader update keeps the public version name at `1.0.0` while raising the Android version code to `11` for in-place updates over the preceding public build.

| Area | Change |
|---|---|
| Launch | The first interface is shown immediately while background services initialise. |
| Reading comfort | The calm persisted light and dark themes are retained, with automatic Arabic RTL and English LTR direction. |
| Notifications | The in-app centre displays publication events only; opening an event takes the student to the exact published item and marks it read locally. |
| Clarity | Removed nonessential instructional copy from the student experience. |
| Android identity | Replaced the black-field launcher treatment with a clean adaptive icon that preserves the original CyKun shield. |
| Trust | APK signature verified; checksum is recorded in [VERIFICATION.md](docs/VERIFICATION.md). |

For complete details, read the [Production Refresh release notes](docs/RELEASE_NOTES_20260815.md).

## v1.0.0 — Public Student Release

CyKun v1.0.0 is the public distribution baseline for the signed Android Reader.

| Area | Change |
|---|---|
| Student experience | Established the direct academic path: **Stage → Semester → Subject → Numbered Lecture**. |
| Learning materials | Supports in-app text lessons and owner-approved PDF resources. |
| Lecture ordering | Uses publisher-defined lecture numbers with a stable fallback for previously published material. |
| Community | Added the in-app Community tab for the official CyS4Ever channel and developer profile. |
| Trust | Added an in-app warning that community links never request passwords or verification codes. |
| Release identity | Published as user-visible version `1.0.0` with Android version code `10` for compatible in-place updates. |

For the original public-release details, see [Release Notes](docs/RELEASE_NOTES_v1.0.0.md).
