# Public Distribution Changelog

## Current presentation

The public CyKun repository has been streamlined as a Reader-only distribution page. It now presents a focused product gallery, current release access, concise installation guidance, and a clear public scope statement.

For the exact APK version, release notes, and integrity value, use the [official Releases page](https://github.com/9gkc/cykun/releases) when a verified Reader build is listed. That page is the single source of truth for downloadable Reader assets.
