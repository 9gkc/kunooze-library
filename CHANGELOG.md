# Changelog

## v1.0.0 — Public Student Release

This is the official public release of **Kunooze Library** for students. It provides the Arabic right-to-left reader experience, structured navigation through stages, semesters, subjects, and materials, in-app text lessons, approved PDF resources, catalogue search, and active owner-published announcements.

The associated repository is intentionally limited to the signed Reader APK, its screenshots, and student-facing English documentation. The private owner publishing workflow is not part of this public distribution.
